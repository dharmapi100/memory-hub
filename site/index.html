How it works

Installed once.
Remembered by everyone.

No cloud account. No sync settings. No vendor. One command wires every MCP-capable agent on your Mac into the same memory.

1

Install

Grab the DMG from the latest release, or run the one-line install. Your memory becomes a single file at ~/.memory-hub/memory.db. That file is yours. Back it up like a dotfile.

2

Connect

The installer detects every agent on your machine — Claude Code, Cursor, opencode, Hermes, Windsurf — and wires them in automatically. No config editing.

3

Work

Each agent calls brief() at session start and remember() when it learns something. Switch agents mid-project and pick up exactly where the last one stopped.

Features

Small tool.
Strong opinions.

Memory is not storage. It is claims with provenance — and when claims collide, you are the judge.

→Conflict detection

When two agents write contradicting facts, both are flagged and surfaced with a warning. The hub never silently picks a winner. You settle it once; it stays settled.

→Consolidation

Near-duplicate memories get merged automatically on your terms. The brief your agents load at session start stays small, current and contradiction-free.

→Nothing is ever lost

Corrections supersede, removals archive. Every version of every memory stays on disk, auditable, forever. Memory you can diff.

→Provenance on every fact

Every memory records which agent wrote it and when. When facts disagree, source reputation — not recency — breaks the tie.

→Agent-agnostic by design

Built on MCP, the protocol your agents already speak. New agent tomorrow? Point it at the hub. No plugins, no per-tool integrations to maintain.

→Local-first, permanently

One SQLite file. No account, no telemetry, no subscription. The labs keep your memory walled per-vendor — that is their lock-in, not your feature.

FAQ

Reasonable doubts.

Don't ChatGPT and Claude already have memory?
Inside their own walls, yes. Claude's memory will never write into Hermes. The labs store memory per-vendor because it is their lock-in. The cross-agent layer is structurally something they cannot build for you.
What happens when two agents disagree?
The hub flags both memories, keeps both, and warns every agent that reads them. Nothing is silently overwritten. You resolve it once with a single correction and the flags clear automatically.
Does my data leave my computer?
No. There is no server, no account, no telemetry. The entire product is one script and one SQLite file on your disk. Sync across machines is on the roadmap via plain old file sync — still yours, still local.
Is this free?
Yes — open source, MIT licensed. It costs nothing to run, because it runs on your machine.
Which agents are supported?
Anything that speaks MCP: Claude Code, Cursor, opencode, Windsurf, Hermes, and any custom agent. If it can call a tool, it can share your memory.
